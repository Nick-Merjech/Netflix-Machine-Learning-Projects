# Task 1 – Netflix Content Recommendation System

This project develops a content-based recommendation system that suggests
similar Netflix titles based on genres, categories, and other content attributes.

## Objectives

- Prepare content-related features
- Convert text data into a machine-readable format
- Calculate content similarity scores
- Generate recommendations for selected titles
- Evaluate recommendation quality

## Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- TF-IDF Vectorization
- Cosine Similarity
